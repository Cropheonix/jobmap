## 结论

1. **每个重点行业都存在"谷德等价物"，但形态各异**：互联网是 V2EX（API 最干净）、设计是谷德（payload 接口）、高校是 gaoxiaojob（部分受限）、远程是远程.work（DOM）。医疗（丁香）与部分社区（电鸭/站酷）被风控或 SPA 挡住——印证四层架构的必要性。
2. **垂直站通道已完全不依赖搜索引擎配额**：三引擎连续两日限流期间，谷德+V2EX 单日入库 181 条真实职位（含薪资字段）。
3. **T3 探测降级机制必要且已实现**：archiposition 403、BOSS JS 挑战都会被「一次探测 → `domain_access_state` 永久降级 → 只走索引线索」策略吸收（含 WAF 壳页特征识别）。
4. **T2 索引层是商业平台职位的唯一稳定通道**：索引摘要按「暂时线索」处理（evidence 带许可注记），长期职位库建立在允许保存的企业自有公开数据、用户导入与授权接口之上。
5. **每周增量是正确节奏**：OrgWatch 快照对比把请求量降一个数量级；国家公共招聘网 https TLS 不兼容已由 gov 站 http 降级重试吸收。
