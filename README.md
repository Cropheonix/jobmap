# JobMap 求职情报地图

> 本地优先、开源的**全行业**招聘信息搜索与分析工具。Windows 优先，第一阶段为本地网页版：启动后浏览器访问 `http://127.0.0.1:<端口>`，数据全部保存在本机，无云端服务、无账号、不上传任何个人信息。

![界面](docs/screenshot.png)

## 功能特性（v1.0，M0+M1 里程碑）

- **多源搜索管线**：多源搜索 → 信息提取 → 去重校验 → 权重排序 → 地图标点 → 导出报告，六步状态实时可视，单个来源失败不阻断其他来源，支持取消。
- **可解释五维评分**（算法 v1.0.0）：岗位匹配 M × 薪资 P × 团队与项目 C × 来源可信度与时效 R × 通勤距离 D；权重滑块自动归一化，**拖动即时重排、不联网**；每条职位可展开分项得分、构成明细与缺失项。
- **诚实的缺失处理**：薪资未披露/无法定位取中性分 50 并显著标注，绝不伪造数值；证据完整度独立展示，低于 40% 标记「建议人工核实」；严格区分「页面可访问」与「确认在招」。
- **去重合并**：同一规范 URL / 同源同帖强合并；同公司相似职位疑似合并；合并后折叠为「来自 N 个来源」并保留全部原始链接。
- **地图联动**：Leaflet 地图按机构类型着色的编号标点，榜单 ↔ 地图双向定位；地址精度分级（门牌/楼宇、街区/园区、行政区示意、无法定位），不可定位的职位不会出现虚假精确标点；WGS-84 统一存储，可配置 GCJ-02 底图自动换算。
- **求职进度管理**：收藏 / 准备投递 / 已投递 / 面试 / Offer / 不考虑 + 备注，全部本地存储。
- **导出与导入**：UTF-8-SIG CSV（Excel/WPS 无乱码、防公式注入）、独立 HTML 分析报告（含来源与评分说明、离线可开）、JSON；支持导入 JSON/CSV 与手动登记职位 URL。
- **全行业覆盖**：内置 11 个行业类别的虚构演示数据 50 条（成都为主 + 北京/上海/深圳/杭州），设计类岗位只是其中之一。

## 快速开始

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 启动（自动挑选端口并打开浏览器；仅监听 127.0.0.1）
python run.py

# 运行测试
python -m pytest tests/ -q
```

Windows 双击 `scripts/start.bat` 即可。

首次启动自动导入演示数据并完成首轮评分。断网时地图底图不可用，但列表、筛选、排序、导出照常工作。

## 项目结构

```text
jobmap/
├─ run.py                    # 启动入口（127.0.0.1 + 随机端口 + 自动开浏览器）
├─ backend/
│  ├─ main.py                # FastAPI 应用（lifespan 建库 + 种子）
│  ├─ api/                   # jobs / search / map / export / prefs / system
│  ├─ core/                  # 配置、会话令牌、URL 校验、CSV 防注入
│  ├─ db/                    # SQLAlchemy 模型、SQLite(WAL)、种子、评分重算
│  ├─ providers/             # 数据源插件（base + 示例源 + 注册表）
│  ├─ pipeline/              # 坐标换算、去重、记录装载
│  ├─ ranking/               # 评分引擎 v1.0.0（五维/缺失中性/完整度）
│  └─ exports/               # HTML 报告模板（Jinja2）
├─ frontend/                 # 无构建静态前端：Vue3 + Leaflet（vendor 随包分发）
├─ sample-data/              # 50 条全行业虚构演示数据（is_demo 标记）
├─ tests/                    # 31 项自动化测试（评分边界/坐标/去重/安全/API）
└─ scripts/                  # Windows 启动脚本
```

## 主要 API（自动文档见 `/api/docs`）

| 接口 | 说明 |
|---|---|
| `POST /api/search/tasks` | 提交搜索任务（返回任务 ID，后台执行） |
| `GET /api/search/tasks/{id}` | 任务进度与六步状态；`/cancel` 取消 |
| `GET /api/jobs` | 过滤 / 排序 / 分页 / 全文检索 |
| `PATCH /api/jobs/{id}/action` | 收藏、投递进度、备注 |
| `PUT /api/preferences` | 权重、期望薪资、通勤出发点、底图配置 |
| `POST /api/scores/recompute` | 按新偏好重算全部子分 |
| `GET /api/map/points` | 定位点（WGS-84 + 精度分级） |
| `GET /api/export?format=csv\|json\|html` | 导出当前筛选集合 |
| `POST /api/import` | 导入 JSON/CSV |

修改类接口需携带本地会话令牌（`X-JobMap-Token`，由 `/api/session/config` 下发），服务只绑定回环地址。

## 评分算法（摘要）

`综合分 = Σ wᵢ·sᵢ / Σ wᵢ`，默认权重 M30 / P25 / C20 / R15 / D10，五个滑块全为零时回退默认。缺失维度取中性分 50 并计入缺失清单；R 是「信息可靠程度估计」，不是在招认证；已截止/下架岗位在排序中门控沉底。每次计算保存算法版本、权重快照与子分，导出报告可复现当时排序。完整说明见界面「📖 算法解释」。

## 数据合规边界

- 内置演示数据为**虚构样本**（卡片带「演示」徽标），不可作为真实招聘信息引用；接口真实数据源在 M2 里程碑接入，仅使用许可允许的来源，不规避登录/验证码/反爬，无法访问时标记 `access_restricted` 而非伪装成功。
- 不抓取 HR 个人联系方式；仅缓存岗位元数据、摘要与来源链接，保留归属。
- 地图默认使用 OpenStreetMap 标准瓦片并遵守其使用政策（禁止批量预取）；底图可在设置中替换为你有合法使用权的任意瓦片服务。
- 详见 [NOTICE.md](NOTICE.md)。

## 路线图

- **M0 ✅** 数据规范与全行业演示数据（50 条，来源/缺失值可追溯）
- **M1 ✅** 可操作的本地页面：筛选、五维权重即时重排、地图联动、收藏、进度、CSV/HTML/JSON 导出、离线浏览
- **M2 ⏳** 接入真实合规来源（企业官网抓取、授权搜索 API、公开招聘公告插件）、URL 抓取与证据快照、增量更新
- **M3 ⏳** 可分发 Windows 版本：PyInstaller 打包、pywebview 壳、SQLite 备份恢复、首启引导
