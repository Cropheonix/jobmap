📖 评分算法解释（v{{ session.algorithm_version }}）

综合分 = 岗位匹配(M)×w₁ + 薪资(P)×w₂ + 团队(C)×w₃ + 可信度(R)×w₄ + 通勤(D)×w₅ + 公司风险(V)×w₆，权重由滑块设置并归一化。当前权重： {{ label }} {{ weightsPct(key) }}%　

  • M 岗位匹配度：职位标题 35% + 职责正文 35% + 行业/类别 20% + 技能关键词 10%（基于关键词规则，不依赖云端 AI）。
  • P 薪资匹配：岗位公开区间与你的期望区间重叠度；多薪月适度加成。薪资未披露取中性分 50 并标注「薪资未披露」，绝不伪造。
  • C 团队与项目：行业契合 30% + 可核实代表项目 25% + 成长路径 20% + 规模稳定性启发 15% + 机构偏好 10%。不以规模天然偏大公司。
  • R 来源可信度与时效：来源可核实度 35% + 官方入口可见 25% + 发布/核查时效 25% + 字段完整 15%。R 是信息可靠度估计，不是「保证在招」认证。
  • D 通勤距离：与出发点的直线距离分档（粗略参考，标注非路径距离）；无出发点或无坐标取中性分 50。
  • V 公司风险（v1.1 新增）：消费口碑信号（知乎/小红书/贴吧证据 + 本地负面词规则）与法律信号（被执行/劳动仲裁/行政处罚/欠薪黑名单）。置信度 <0.7 的信号只展示不评分；无证据取中性 50——查不到≠安全也≠危险。可在滑块处把 V 权重调零整体关闭。

缺失与完整度：缺失 ≠ 零分。证据完整度独立于总分展示；低于 40% 标记「建议人工核实」。

状态门控：已截止/已下架岗位默认沉底并置灰，不混入可投递区；「状态未核实」的岗位保留但不高亮为在招。页面可访问 ≠ 正在招聘。

审计：每次计算保存算法版本、权重快照与子分，导出报告可复现当时排序。
